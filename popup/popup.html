🚀 How It Works

  1. Configure: Enter your GitHub Personal Access Token in the Settings tab.
  2. Solve: Open any problem on LeetCode and click Submit.
  3. Automatic Sync: When Accepted, the extension calculates Time & Space Complexity and commits the solution directly to your GitHub repo.

🔁 Repeated Questions (Multi-Solution)

When you solve a question again (e.g. optimizing or trying a new language/approach), it checks the existing folder and automatically names the new file Solution_2, Solution_3, etc., and updates the comparison table in README.md!

⏱️ Time Complexity Analysis

Each solution includes the algorithmic Time and Auxiliary Space Complexity right at the top of the code file, in the problem README.md, in the Git commit message, and in an animated toast on LeetCode!
